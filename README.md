# Ramon Bikes Elétrica

Apresentação digital da Ramon, com catálogo de modelos e contato pelo WhatsApp.

Site estático em HTML, CSS e JavaScript. Hospedagem pelo GitHub Pages a partir da raiz da branch main.

As fotos do catálogo apresentam os modelos. A imagem principal é uma composição ilustrativa de campanha. Valores, configurações e disponibilidade devem ser confirmados com a equipe.
